Privacy Policy

This privacy policy applies to the Contextual Answer Highlight Extension, which uses Large Language Models (LLMs) to generate answers based on user-highlighted text in the browser.

Data Collection and Usage

This extension does not collect or transmit any personal information or user-identifiable data. All text highlights and responses are processed locally in the browser.

  • Highlighted text is temporarily used to request a response from a third-party LLM API (e.g., Google Gemini, OpenAI, Anthropic, Hugging Face, etc.).
  • No data is stored remotely unless optional authentication and server-based storage (e.g., Redis) is enabled by the user.
  • All highlights, generated responses, and history are saved using browser-based LocalStorage or IndexedDB.

Third-Party Services

This extension may interact with third-party APIs solely to fetch AI-generated responses. These services have their own privacy policies and may log usage data for performance and abuse prevention.

User Control

  • Users have full control over their stored data via browser storage.
  • No user data is transmitted or synced across devices unless they explicitly enable authenticated storage.
  • The extension does not display ads or use tracking mechanisms.

Compliance

We adhere to the Chrome Web Store Developer Program Policies and relevant data protection laws. No personal or sensitive user data is collected or shared.
